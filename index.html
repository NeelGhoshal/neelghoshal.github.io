Projects

Course Tutor: Multi-Agent RAG

Python, Ollama, Chroma, RAG, Streamlit, Multi-Agent Systems

Show descriptionHide description

A four-agent retrieval-augmented tutor for a Mathematics for Machine Learning course, answering only from the course's lecture slides and textbook: a Router classifies each question as lecture, textbook, or off-topic; a Tutor retrieves the relevant chunks and answers with page citations; a Verifier checks every claim against the retrieved text and triggers a retry if one is unsupported; and a Quizzer writes and grades quiz questions, logging missed topics to revisit first next time. Runs entirely on a local, open-weight LLM with no API key.

Code on GitHub

Paper Librarian: MCP Research Library

Python, MCP, SQLite, sentence-transformers, PyMuPDF

Show descriptionHide description

A local MCP (Model Context Protocol) server that gives Claude a searchable library of research papers: add papers by arXiv ID or PDF path, and Claude can search them, answer questions with section and page citations, compare papers, and follow citation links between papers in the library. Everything runs on-device, combining vector embeddings with BM25 keyword search over a local SQLite index, with no external service beyond arXiv downloads.

Code on GitHub

Cedarline: Insurance Service Agent

Python, Salesforce Agentforce, Data Cloud, Snowflake, pandas

Show descriptionHide description

A Salesforce Agentforce member service agent for Cedarline Health Plan, a hypothetical medical insurer: verifies a member's identity, then answers questions about claims, denial reasons, deductible and out-of-pocket balances, prior authorizations, service requests, and appeals, using only that member's own records. A data pipeline turns ~1,160 Synthea sample patients into Cedarline's data, adding it to Snowflake and to Salesforce Data Cloud, and feeds an Agentforce Data Library the agent searches to answer questions.

Veritas: Multi-Agent Document Review

MLH Best Use of Snowflake Winner

Python, LangGraph, Streamlit, Snowflake Cortex, Multi-Agent Systems

Show descriptionHide description

A document integrity review tool built for the ATO Hackathon: paste in a bill, resolution, or article, and four AI agents run in parallel, checking its completeness and sourcing, verifying its factual claims against live web search, confirming the authority of the people named in it, and flagging internal or external contradictions by severity. A LangGraph graph orchestrates the agents and merges their findings into one report.
